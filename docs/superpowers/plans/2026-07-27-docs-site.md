# Doc Site (Storybook replacement) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Storybook with a lightweight, own-built Vite+React doc site (`docs-site/`) that reads existing `.stories.tsx` files and deploys to GitHub Pages, while moving a11y/interaction test coverage into `vitest` so it no longer depends on Storybook addons.

**Architecture:** `docs-site/` is an isolated Vite+React app (own `vite.config.ts`/`tsconfig.json`) that discovers `.stories.tsx` files under `src/components/**` via `import.meta.glob`, groups them by `meta.title`, and renders each story with a generated prop-controls panel driven by `meta.argTypes`. Story files migrate from `@storybook/react` types to a small local type module `src/docs-types.ts` (lives in the lib, not in `docs-site/`, so `docs-site` depends on `src` in one direction only — the lib's own `tsconfig`/`pnpm typecheck` never reaches into `docs-site/`). A11y checks move into each component's `.test.tsx` via `vitest-axe`. A new GitHub Actions workflow builds and publishes `docs-site/dist` to Pages on every push to `main`.

**Tech Stack:** Vite, React 19, TypeScript, Tailwind CSS v4 (`@tailwindcss/vite`), vitest, `@testing-library/react`, `vitest-axe`, GitHub Actions (`actions/upload-pages-artifact`, `actions/deploy-pages`).

## Global Constraints

- `docs-site/` must not affect `pnpm lint`, `pnpm typecheck`, `pnpm build`, or `pnpm test` for the lib — it has its own `tsconfig.json` and is not part of `src/`.
- No pnpm workspace / `pnpm-workspace.yaml` — `docs-site/` stays a plain folder with its own Vite config, not a separate package.
- Shared type module lives at `src/docs-types.ts` (inside the lib), not inside `docs-site/`.
- Single-page nav (no react-router) — sidebar list, click swaps the selected component in local state, no URL routing.
- Existing `.stories.tsx` content (named story exports, `render` functions, `args`) is preserved as-is; only the type import changes and `tags: ['autodocs']` is removed.
- A11y test per component uses `vitest-axe`'s `axe()` + `toHaveNoViolations()`, added to the existing `.test.tsx` file (not a new file).
- GitHub Pages workflow triggers on `push` to `main`, uses `actions/upload-pages-artifact` + `actions/deploy-pages` (matches the pattern of `permissions: pages: write, id-token: write`).
- Every removed Storybook reference (`package.json` scripts/deps, `.storybook/`, `eslint.config.js` plugin, `CLAUDE.md`) must actually be deleted, not commented out.

### Task 10: Story loader (`loadStories.ts`)

**Files:**
- Create: `docs-site/src/loadStories.ts`

**Interfaces:**
- Consumes: nothing external — reads `.stories.tsx` modules directly via `import.meta.glob`.
- Produces: `type LoadedStory = { name: string; args?: Record<string, unknown>; render?: (args: Record<string, unknown>) => ReactNode }`, `type LoadedComponentDoc = { title: string; group: string; page: string; meta: Meta; stories: LoadedStory[] }`, and a function `loadStories(): LoadedComponentDoc[]`. Task 11 (`StoryRenderer`) consumes `LoadedComponentDoc['meta']` + one `LoadedStory`. Task 12 (`App.tsx`) consumes the full `LoadedComponentDoc[]` array.

- [ ] **Step 1: Write `docs-site/src/loadStories.ts`**

```ts
import type { ReactNode } from 'react'
import type { Meta, StoryObj } from '../../src/docs-types'

export type LoadedStory = {
  name: string
  args?: Record<string, unknown>
  render?: (args: Record<string, unknown>) => ReactNode
}

export type LoadedComponentDoc = {
  title: string
  group: string
  page: string
  meta: Meta
  stories: LoadedStory[]
}

type StoryModule = {
  default: Meta
  [exportName: string]: Meta | StoryObj | undefined
}

export function loadStories(): LoadedComponentDoc[] {
  const modules = import.meta.glob<StoryModule>('../../src/components/**/*.stories.tsx', {
    eager: true,
  })

  const docs: LoadedComponentDoc[] = []

  for (const mod of Object.values(modules)) {
    const meta = mod.default
    if (!meta?.title) continue

    const [group, ...rest] = meta.title.split('/')
    const page = rest.length > 0 ? rest.join('/') : meta.title

    const stories: LoadedStory[] = Object.entries(mod)
      .filter(([exportName]) => exportName !== 'default')
      .map(([name, story]) => {
        const s = story as StoryObj
        return { name, args: s.args, render: s.render as LoadedStory['render'] }
      })

    docs.push({ title: meta.title, group, page, meta, stories })
  }

  return docs.sort((a, b) => a.title.localeCompare(b.title))
}
```

**Interfaces:**

- Produces: `StoryRenderer` component, props `{ doc: LoadedComponentDoc; story: LoadedStory }`. Task 12 (`App.tsx`) renders one `<StoryRenderer>` per story.

- [ ] **Step 1: Write `docs-site/src/StoryRenderer.tsx`**

```tsx
import { useState } from 'react'
import type { LoadedComponentDoc, LoadedStory } from './loadStories'

type Props = {
  doc: LoadedComponentDoc
  story: LoadedStory
}

export function StoryRenderer({ doc, story }: Props) {
  const [args, setArgs] = useState<Record<string, unknown>>({
    ...doc.meta.args,
    ...story.args,
  })

  const argTypes = doc.meta.argTypes ?? {}
  const controlKeys = Object.keys(argTypes)

  const Component = doc.meta.component as React.ComponentType<Record<string, unknown>> | undefined

  return (
    <div style={{ marginBottom: 32, padding: 16, border: '1px solid #e5e5e5', borderRadius: 8 }}>
      <h3 style={{ fontSize: 14, fontWeight: 600, marginBottom: 12 }}>{story.name}</h3>

      {controlKeys.length > 0 && (
        <div style={{ display: 'flex', gap: 12, marginBottom: 16, flexWrap: 'wrap' }}>
          {controlKeys.map((key) => {
            const argType = argTypes[key]!
            const value = args[key]

            if (argType.control === 'boolean') {
              return (
                <label key={key} style={{ fontSize: 12 }}>
                  <input
                    type="checkbox"
                    checked={Boolean(value)}
                    onChange={(e) => setArgs((a) => ({ ...a, [key]: e.target.checked }))}
                  />{' '}
                  {key}
                </label>
              )
            }

            if (argType.control === 'select') {
              return (
                <label key={key} style={{ fontSize: 12 }}>
                  {key}{' '}
                  <select
                    value={String(value ?? '')}
                    onChange={(e) => setArgs((a) => ({ ...a, [key]: e.target.value }))}
                  >
                    {argType.options.map((opt) => (
                      <option key={opt} value={opt}>
                        {opt}
                      </option>
                    ))}
                  </select>
                </label>
              )
            }

            return (
              <label key={key} style={{ fontSize: 12 }}>
                {key}{' '}
                <input
                  type="text"
                  value={String(value ?? '')}
                  onChange={(e) => setArgs((a) => ({ ...a, [key]: e.target.value }))}
                />
              </label>
            )
          })}
        </div>
      )}

      <div>
        {story.render ? story.render(args) : Component ? <Component {...args} /> : null}
      </div>
    </div>
  )
}
```
