# Security Policy

## Supported Versions

This library is pre-1.0 and moves quickly. Security fixes are released against the latest published `0.x` version — there are no separate maintenance branches yet.

| Version | Supported |
|---------|-----------|
| Latest `0.x` | ✅ |
| Older `0.x` | ❌ |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report it privately via [GitHub Security Advisories](https://github.com/Starbem/react-starsystem/security/advisories/new) for this repository. Include:

- A description of the vulnerability and its potential impact
- Steps to reproduce (a minimal repro repo or code snippet helps)
- The affected version(s)

We'll acknowledge reports as soon as possible and follow up with a fix timeline once the issue is confirmed.
