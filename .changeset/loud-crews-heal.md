Add DropdownMenu component (ID-3186) built on @radix-ui/react-dropdown-menu, with `item`/`separator`/`label`/`checkbox-item`/`sub-menu` entry types, icon and badge support per item, configurable `trigger`/`align`, an `onSelect` callback, and full keyboard navigation (arrows, Enter, Escape).

New runtime dependency: `@radix-ui/react-dropdown-menu`.
